# EXTRAS (XT) — small convenience and delight features

All run on the phone, no server. Each has a feature key so a gym can lock it. Specs in `contract/engines.md` 20-25.

| Feature | Behaviour | Phase |
|---|---|---|
| Today card | Home card: today's planned day (or best recovered day), est. time, exercise count, big Start | 32 |
| Why chips | One plain sentence per suggestion, e.g. "Your lats have rested 4 days and got little work this week" | 15, 18 |
| Machine finder | Pick a muscle, see best machines with photo | 18, 23 |
| Equipment mode | Hotel/home/minimal presets filter everything | 19 |
| Form cue card | 3 cues + 1 common mistake before a new exercise, dismissible | 21 |
| Workout in a pinch | 15-60 min builder, respects marks and equipment mode | 33 |
| Superset swipe | Swipe through partner suggestions | 33 |
| Plate calculator | Target weight -> plates per side; editable bar and plates | 38 |
| Warm-up ramp | 50/70/85% ramp for heavy compounds; not counted as volume | 38 |
| Smart rest timer | Default by exercise type, learns your real rests | 38 |
| Big-number gym mode | Huge type, high contrast, screen stays awake | 38 |
| Last-time inline | "Last: 60 kg x 10, 10, 9" with an up/hold arrow | 38 |
| PR celebration + wall | Short gold burst, reduced-motion safe; all records on one page | 39 |
| Weak-spot finder | "Rear delts got 2 sets while chest got 18" + one-tap add | 44 |
| Streaks + ring | Weekly target ring; planned rest days never count against you; grace week | 53 |
| Year-in-review | Swipeable cards for any period | 61 |
| Muscle of the week | One daily-life fact per week from the atlas | 61 |
| Routine image | Plan drawn as a 1080x1350 gold-on-dark image, made on the phone | 61 |

## Why-chip sentences (Phase 15/18 finalise wording)
recovered: "<Muscle> has rested <n> days." · neglected: "<Muscle> got little work this week." · in_routine: "It is in your <day> plan." · built_by_you: "You built this one." · same_variation: "Same movement, different setup." · favourite: "One of your favourites." · progress_ready: "You hit your reps last time, time to go up." · balances_week: "It balances your week."

## Rules
No shaming, no medical claims, no streak guilt (rest is allowed), animations respect reduced motion, nothing bleeds.
